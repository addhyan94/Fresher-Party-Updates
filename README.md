## ✨ About The Project

A premium black & gold themed digital invitation system built using **React + Vite + Supabase**.

This system allows real-time guest approval with a luxury animated celebration experience.

---

## 🚀 Features

### 👤 Guest Side
- Guest ID Login  
- Real-time approval status  
- Waiting screen animation  
- Countdown timer  
- Celebration animation  
- Background music  
- Fully responsive design  

---

### 🛠 Admin Panel

Access Admin Panel:

https://addhyan94.github.io/Fresher-Party-Updates/#/admin

Admin Capabilities:
- Approve guests  
- Reject guests  
- Manage guest list  
- Real-time database updates  
- Secure Supabase integration

## ⚙️ Local Development Setup

```bash

```

## 🚀 Deployment

Deploy to GitHub Pages:

```bash
npm run deploy
```

This pushes the production build to the `gh-pages` branch automatically.

---

## 🛣 Routing Configuration

This project uses:

```
createHashRouter()
```

Because GitHub Pages does not support server-side routing.
